# What happened

Measured, dated, and never hand-edited. Observations go in as they are taken, and stay.

The rule that makes this useful: if you find yourself wanting to correct a number here, the
fix belongs upstream in whatever produced it, not in this folder.

```
data/
├── observations/    one file per metric per period
├── commitments/     what someone said they would do, and by when
└── notes/           context that is not a number
```
