# Metrics

One number per person. The number that describes what they are permanently accountable for — not this quarter’s project.

## What this file has to answer

- What is each person’s one number?
- How is it computed, from which source?
- What period does it cover?
- Which numbers have no source yet, and are therefore claims rather than measurements?
