# Hiring

How roles get opened, run and closed.

## What this file has to answer

- What has to be true before a role opens?
- What is the standard process?
- Who decides?

## Yours

_Delete everything below and write your own._

**Before opening.** The work exists today, one person is named as drowning in it, and the
metric the hire will own is written down.

**Process.** Screen · craft interview with a real problem · two-way session with the team ·
reference calls the hiring manager makes personally.

**Decision.** Hiring manager, consulted with the founder.
