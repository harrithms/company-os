# Principles

How decisions get made when nobody senior is in the room.

## What this file has to answer

- What do you actually do when two good things conflict?
- Can each principle be used to reject a real proposal?

## Yours

_Delete everything below and write your own._

**Say the number.** Bring the figure, not the impression. "Slow" is not a measurement.

**One owner, always.** Shared ownership is nobody’s. If two names appear, pick one.

**Decide, then write it down.** A decision that only exists in a meeting did not happen.
