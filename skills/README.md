# The repeatable jobs

The handful of routines that happen often enough to be worth writing down once.

- **set-accountability** — give a person a metric and a goal, and record who agreed it
- **plan-quarter** — roll the quarter over: grade, retrospect, set the next bets
- **run-weekly-review** — assemble what changed and what needs a decision
- **diagnose-metric** — work out why a number moved, or why it cannot be trusted
- **prepare-report** — generate weekly, monthly or board from the files
- **update-company-context** — keep `os/` current when something changes upstream

Write each as a checklist a person or an agent can follow. They are instructions, not code.
